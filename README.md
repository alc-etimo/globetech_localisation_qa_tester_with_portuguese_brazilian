# Portfolio: Localisation QA Tester (Remote - Europe)

## 📌 About this portfolio

Online portfolio developed for the **Localisation QA Tester with Portuguese Brazilian** role at GlobeTech (remote position based anywhere in Europe). The portfolio emphasises experience with **software documentation, print items, help content, and terminology governance**.

## 🎯 Target role

- **Position:** Localisation QA Tester
- **Location:** Remote (anywhere in Europe)
- **Focus:** Software documentation, help content, print items, hardware labels, terminology management

## 🛠️ Case studies included

1. **Content Governance & QA Leadership** — documentation governance for 30k+ users, reducing 15k → 10k items
2. **Terminology Governance** — terminology system 700 → 2,700+ terms, synchronising documentation ↔ UI
3. **Cross-Platform Documentation Testing** — test matrix focused on print/docs, help content, hardware labels
